.. py:function:: dispatch_github_workflow(repo: str, workflow_file: str, ref: str, token: str, inputs: dict[str, str] | None = None) -> None

   Trigger a workflow_dispatch event on a GitHub Actions workflow.

   :param repo: GitHub repo in "owner/name" form (e.g. "catalyst-cooperative/pudl").
   :param workflow_file: Workflow filename (e.g. "zenodo-data-release.yml").
   :param ref: Git branch or tag to run the workflow from.
   :param token: Bearer token to authenticate to GitHub.
   :param inputs: workflow_dispatch inputs, if the workflow takes any.
